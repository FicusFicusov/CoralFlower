Stopped before "Switching to update mode"? Nothing was written. Plug the cable back in and press Install again.

Before you start
  1. Use Chrome or Edge on a computer. Other browsers cannot talk to the FM-1.
  2. Charge the FM-1 fully. It runs on its own battery while it writes.
  3. Connect it with a USB data cable, straight to the computer. No hub.
  4. Close other apps that use MIDI, such as a DAW or a synth editor.
  5. When the browser asks to use MIDI devices, allow it.
  6. Keep this page open and the computer awake. Do not unplug the cable until you see Done. It takes about a minute.

Installing firmware is at your own risk. CoralFlower is free software and comes with no warranty.

You can always go back: the official M-VAVE firmware can be reinstalled from m-vave.com.

Back up and restore

A backup is one .json file. It holds everything saved on the FM-1: the settings, the 32 user sounds with their patches, the loops and the sound banks.

Restore writes a backup back. It checks every part before it writes anything, then restarts the FM-1. Stop any loop first.

Works with CoralFlower, ChoralRoot and Felucca. The official firmware cannot be backed up.

Device not found, or the install stopped?

Check the cable first. Use a data cable, straight to the computer, not through a hub. Close other apps that use MIDI. Switch the FM-1 on and press Install again.

Start update mode by hand. Switch the FM-1 off. Hold OCT− and switch it on. The key lights flash three times and the screen stays black: the FM-1 is in update mode. Press Install. To leave update mode without installing, switch the FM-1 off and on. This works on an FM-1 that runs CoralFlower, or ChoralRoot 0.16 or later.

One long flash instead of three? Switch off for 10 seconds and try once more. One long flash again means no update loader is stored. The FM-1 then shows up as the USB disk described here until you switch it off.

While CoralFlower runs, you can also hold OCT−, OCT+ and HOME for five seconds. A countdown shows; let go to cancel. Then the FM-1 is in update mode.

A screen that says SAFE MODE? The firmware crashed twice while starting. It now starts without your saved data, which stays untouched. Back up and Install both work in safe mode. Switching off and on tries the saved data again.

A black screen, and a USB disk named WL82 UBOOT1.00 (USB ID 4C4A:8057) instead of the FM-1? That is the chip's ROM boot mode. The firmware does not start, and this page cannot reach it. Do not format that disk. These recovery tools put the official V15 back over the same cable: MvaveFM1Unbricker.

Nothing shows up at all, not even that disk? The hardware route is the FM-1 Transporter, a small RP2040 board on the USB lines: FM-1-transporter.

Return to the official firmware

The official firmware cannot use CoralFlower's sounds, loops or settings. This page saves them to a backup file first. To bring them back, install CoralFlower again and press Restore.

Get the official FM-1 V15 firmware from M-VAVE Downloads and choose the unmodified FM-1.fwsc file. The file is checked here in the browser. It is not uploaded anywhere.

To come back: install CoralFlower with the Install button above, then press Restore and choose that backup file.

The return to the official firmware stopped.

Stopped before "Switching to update mode"? Nothing was written. Plug the cable back in and press the button again.

Stopped while writing, and the FM-1 is still on? It waits in update mode, with a black screen. Plug the cable back in, tick "Resume an update that was cut off" and press the button again, with the same official file chosen.

Switched off, or the battery ran out? Switch it on and do the same. If this page does not find it, see Device not found.
